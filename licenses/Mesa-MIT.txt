Mesa 3D Graphics Library — MIT License
======================================

Anvil's V3D support derives hardware-description material from the Broadcom
V3D backend of Mesa, pinned to tag `mesa-24.3.4`, commit
769e51468b49b2a42f0a0eaf71cf9eed5ff4e5de.

The material used is the control-list packet description
(`src/broadcom/cle/v3d_packet.xml`), the QPU instruction field/opcode tables
(`src/broadcom/qpu/qpu_pack.c`, `qpu_instr.{c,h}`), the instruction-restriction
list (`src/broadcom/compiler/qpu_validate.c`), the TFU and tiling layout
descriptions (`src/broadcom/common/v3d_tfu.h`, `src/gallium/drivers/v3d/*`),
and the register-write order of the simulator's job submission
(`src/broadcom/simulator/v3dx_simulator.c`). Anvil's files
`RaspberryPi4/Lib/v3d.pi4`, `RaspberryPi4/Lib/v3dqpu.pi4` and
`RaspberryPi4/Lib/neon.pi4` cite those files by name and line.

No Mesa source file is vendored in this repository. The notice below is the
per-file notice those Mesa sources carry, retained here because Anvil
