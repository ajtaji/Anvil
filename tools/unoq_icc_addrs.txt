# unoq_icc_addrs.txt - the 11ae diff list.
#
# One 32-bit physical address per line, "0xADDRESS  NAME  # citation".
# The SAME list is read from Debian (tools/unoq_icc_capture.sh) and from
# the bare-metal probe, so that the two captures diff line for line.
#
# EVERY address here has been read on this silicon already, from one world
# or both.  Nothing is added to this file on the strength of a register
# map alone: on 2026-09-06 three separate SoC resets were caused by
# reading addresses that a register map said existed, including one inside
# a window whose first word read back fine.  A sweep is not allowed and a
# guess is not allowed.
#
# NEVER ADD: 0x04480000 (bimc), 0x01880000 (system_noc), 0x01900000
# (config_noc), or anything inside 0x04690000+0x1000 past offset 0.  The
# first two reset the board on a single read; the third reset it during a
# sweep.  See the header of tools/unoq_icc_capture.sh.
