# Pi 4 Vulkan image readback hardware proof

`RaspberryPi4/Examples/Diagnostics/vulkanImageReadbackProof.pi4` is a returning RAM payload for the public `vkCmdCopyImageToBuffer` path. It first clears a 64×64 linear BGRA8 image through `vkCmdClearColorImage` on V3D. A second command buffer transitions that image to transfer-source layout and copies all 16,384 bytes into a transfer-destination buffer at offset 64. After both fences complete, it requires one bin/render pair, one completed DMA operation, exact `$FF3380B2` for all 4,096 pixels, unchanged 64-byte prefix and suffix guards, a quiescent DMA engine, and restoration of the display owner's prior DMA write bound. It returns zero only if every check passes; nonzero values identify the failed stage.

The IDE compiler's `--compile` path produced a 589,808-byte PMFBOOT v2 container for load/entry `$00600000` and stack `$04F00000`, SHA-256 `A3106AC466D700034C6609BD2DA774DF16194043B711C3FD1F8102A0D04B249D`. The compiler executable SHA-256 was `561E207FC4EDA1818C3FED9A492503CA266B03EA981EEBD590BDF49A40E87D2A`. The raw image is 589,680 bytes. The payload is also in the V3D backend gate's compile list, so future changes must keep it buildable.

The V3D backend gate passed 85 properties over 4,403,870 executed A64 instructions and compiled all eight listed diagnostics. The normal Pi 4 image compiled at build 216, 4,273,368 bytes, SHA-256 `982866F83A49AE3383F3DB27C489F5CF228202D9944DD36D05C3B7B81F940B79`. Its source build stamp was restored to the tracked value after compilation.

The first hardware attempt did not start. The saved direct-Ethernet console address `192.168.137.1:5555` supplied no `pmf>` prompt within 30 seconds, so `board_run_leased.py` sent no payload. Both desktop Ethernet ports were disconnected. The documented Wi-Fi address `192.168.1.22` was unreachable from the desktop's `192.168.1.106`; its TCP console check also failed. The board lease was released with no flash, reset, or boot-medium write. This is a compiled diagnostic, **not** a passed silicon proof.
