The diagnostic clears a 64×64 linear BGRA8 image on V3D, reads the whole image through one guarded DMA operation, then copies a 17×13 rectangle by thirteen guarded DMA operations into a differently sized image. It subsequently reads a 17×13 rectangle beginning at source offset (3,5) into a tightly packed buffer at byte offset 64. The final readback must add exactly thirteen guarded DMA operations, leave DMA quiescent, and restore the monitor's original DMA bounds. The payload checks all 221 copied pixels against the V3D clear colour, plus every byte before and after the destination span against the poison value. All conditions are required for `x0=0`.

The corrected diagnostic allocates a fresh command buffer and passed on the next RAM run. The public command gate passed 699 property checks over 131,444,644 interpreted AArch64 instructions. It exercises a nonzero-offset rectangular readback against an independent byte oracle and checks that destination bytes outside the requested span remain unchanged. The normal Pi 4 image built at 4,276,368 bytes, and the production V3D backend gate passed 85 checks. This proof is limited to one linear BGRA8 region with tightly packed buffer rows. Optimal-tiled images, row-length overrides, multiple regions, mips, layers, and format conversion remain unsupported.
