connection continued an event stream until 5662 ms. Event arrivals were
1560/3613/5661 ms, before and at EOF. Bodies and event metadata matched.

algorithms in the same run. Resident-randomness secure WebSocket echo passed.

four alternating records; handshake declarations are fixtures. Pool lifecycle
uses controlled transport/handshake doubles. It proves four slots, refusal of
a fifth, stale-handle rejection, independent fields, and wipe on payload return.

the same captured bytes; both verdicts are retained. No failed check is hidden.
Eight close cases and fourteen bounded record/partial-send cases passed.
