A step written 'Tls13PauseHook(...)' is a call through a variable, and a call through a variable is treated as a call to every procedure whose address can reach it - followed through the assignments this program writes. Assign the pointer a procedure that does not lead back here, or call by name, to break the loop.
A program on these boards runs for as long as the board has power, and recursion makes how deep the stack goes depend on the data it is given - so no build can prove the stack is big enough, and one input deeper than any before it runs off the end of the stack. Without a loop in the calls, the deepest call chain is fixed when the program is built. Rewrite it iteratively: a While or Repeat loop, with an explicit stack array where the algorithm needs one.
