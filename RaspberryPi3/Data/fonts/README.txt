Pi 3 TrueType console font asset

Copy this directory's files into the fonts/ directory on filesystem
partition 2. The monitor's filesystem path for the bundled face is:

  2:/fonts/CourierPrime-Regular.ttf

The font is Courier Prime Regular, a static TrueType glyf/loca font from
Google Fonts, pinned at commit f2bd09badbc763d8757951d52deec29da27e85fb.
Its SIL Open Font License 1.1 text is included as CourierPrime-OFL.txt.
The font and license bytes are recorded in manifest.json.
